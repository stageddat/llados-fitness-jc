# Llados Fitness Pro+ (Jetpack Compose)
Simple body mass index (BMI) calculator themed by the scammer character and content creator "Llados", built with Jetpack Compose.

## Branches

- `master`: initial working version of the BMI calculator with the basic interface.
- `UI-bonica`: visual redesign in neo-brutalism style (bold fonts, thick black borders, hard shadows, flat colors, BMI color scale and pressable buttons).

## Technologies

- Kotlin
- Jetpack Compose (Material 3, state management, custom modifiers and components, animations, Google Fonts)
- Android Studio / Gradle
